# Підключення вебзастосунку до PostgreSQL через Supabase та JavaScript

Лабораторна робота з організації клієнт-серверної взаємодії між браузерним JavaScript-застосунком та хмарною реляційною базою даних **PostgreSQL** на платформі **Supabase** без використання бекенд-фреймворків.

## 🎯 Мета роботи
Ознайомитися з принципами роботи хмарних баз даних PostgreSQL у середовищі Supabase, налаштувати таблицю з обмеженнями цілісності, реалізувати розмежування прав доступу за допомогою **Row Level Security (RLS)** та забезпечити безпечне читання (`SELECT`) і додавання (`INSERT`) даних через офіційний клієнт `supabase-js`.

```text
